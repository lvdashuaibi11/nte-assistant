# 异环第三方助手 · 使用说明

一个跑在你自己电脑上的本地小工具，用来管多个账号的《异环》日常：游戏内签到、本性像素 / 都市活力 / 活跃度 / 周本次数总览、抽卡统计。

不用安装任何依赖（不用 pip、不用 node）。数据全部存在你自己的电脑上，不上传任何服务器。

---

## 〇、先看目录里有没有 `runtime` 文件夹

| 情况 | 说明 |
|---|---|
| **有 `runtime` 文件夹** | 这是**免安装版**，Python 已经一起打包在里面了。**你什么都不用装**，直接双击 `启动.bat`。 |
| **没有 `runtime` 文件夹** | 这是**标准版**，需要电脑上已有 Python 3.10 以上。没有的话看下面第一节装一个。 |

想确认用的是哪个解释器：在该目录下打开命令行执行 `find_python.cmd --print`，会打印 `Python:` 和 `Source:` 两行。

## 一、第一次使用（标准版）

1. 解压到一个**不带中文和空格的路径**更稳（例如 `D:\nte-assistant`）。
2. 双击 **`启动.bat`**（前台运行，关窗口就停）或 **`后台启动.bat`**（后台常驻，窗口可最小化）。
3. 脚本会自动找电脑里的 Python。找得到就直接开浏览器，地址是：

   ```
   http://127.0.0.1:8765/
   ```

4. 点右上角「导入账号」，输入**手机号 + 验证码**完成授权。

> **必须用 `127.0.0.1`，不要用 `localhost`**，也不要用局域网 IP。工具只监听本机回环地址。

### 没装 Python 怎么办

去 <https://www.python.org/downloads/windows/> 下载 **Windows installer (64-bit)**，安装时**务必勾选 Add Python to PATH**。装完重新双击 `启动.bat` 即可。

不想装、或者没有管理员权限：直接找**免安装版**（带 `runtime` 文件夹的那个包），解压即用。

脚本的查找顺序是：`NTE_PYTHON` 环境变量 → 本目录 `runtime\python.exe` → 各盘符下的用户安装目录 → 上次成功的缓存 → `py -3` → PATH → 常见安装目录。

- 强制重新扫描：`find_python.cmd --rescan`
- 看它到底找到了哪个：`find_python.cmd --print`
- 手动指定：先 `set "NTE_PYTHON=D:\my\python.exe"` 再启动

## 二、几个必须知道的默认行为

| 默认 | 说明 |
|---|---|
| **写操作关闭** | 首次运行不会替你做任何签到。要用签到/补签，先去设置里打开「允许写操作」。 |
| **定时自动化关闭** | 即使开了定时签到，**也永远不会自动补签**（补签花呗果，只能你手动点）。 |
| **凭证加密存本地** | 登录凭证用 Windows DPAPI 加密后存在 `data\vault.json`，换机器或换 Windows 账户就解不开，只在本机有效。 |
| **只监听本机** | 服务只绑 `127.0.0.1:8765`，同网段其他设备访问不到。 |

## 三、每日签到怎么用

1. 打开「允许写操作」开关。
2. 点「一键签到」，或单个账号卡片上的「签到」。
3. 看「任务队列」里状态变 `done`，卡片上显示「今日已签 · +道具×数量」。
4. **完全退出游戏，重新启动，去游戏内邮箱领取。**

### 为什么奖励在邮箱里、背包里没有

官方原文：**（签到奖励可能存在延迟，请前往游戏内邮箱领取奖励邮件）**。奖励不进背包，走邮箱。

关键一点：社区侧（塔吉多）只负责「登记该发什么」，**必须再触发一次角色联动**，游戏服才会把待发放的奖励变成邮件。这个工具在签到成功后会**自动**做这一步（签到当场一次，30 秒后再自动补一次），所以正常情况下你不用额外操作。

为什么要补第二次：签到请求和角色联动如果挤在同一秒，服务端「待发放」记录可能还没落成，联动就会空跑——这正是「签到显示成功、邮箱却是空的，点一下补投递才到帐」的原因。现在这第二次是后台自己跑的，任务队列里会看到一条「后台自动补投递已完成」。

邮件**不会实时推送**：触发投递后要**完全退出游戏再重新进入**，邮箱列表才会刷新。只切到后台不算。

## 四、补签怎么用

前提：**今天已经签到**（官方要求），且呗果够。

1. 卡片底部灰字能看到 `呗果 200 · 可补签 3 次`；点「签到详情」能看到四个指标和 30 天奖励表。
2. 点卡片上的「补签」→ 弹窗会写清：消耗多少呗果、补后余额、补后剩余次数 → 确认。
3. 等几秒，卡片上的呗果 / 剩余次数 / 累计天数会当场刷新。
4. **完全退出游戏重进，去邮箱领。** 投递是自动的，**不用点「补投递」**。

规则：

- 每次消耗 **200 呗果**，**本月上限 3 次**，每月 1 号 00:00 重置次数（呗果不重置）。
- 补的是「当日签到后下一日」的奖励。
- 呗果扣掉**不可逆**。

### 「补投递」是干什么的

日常**不用点**：签到/补签成功时工具已经投递过一次，30 秒后还会再自动补一次。

只有一种情况用得上：**签到/补签显示成功了，完全退出重进游戏、邮箱里还是没有**。这时点一下，然后退出重进再看。

它在「签到详情」弹窗底部，很安全：**幂等、不扣呗果、不重复发奖**，点几次都行。

**千万别为了催奖励去重复点补签** —— 那会再扣一次 200 呗果。

---

## 五、抽卡统计

卡片末尾的「抽卡统计」只看本地已保存的快照，**不刷新、不发官方请求**。要更新数据点「刷新抽卡」。

- 明细里的「本次抽数」= 这次出货花了多少抽；「累计」= 从卡池开端算起。
- 物品中文名来自官方字典接口，没覆盖到的显示 ID，可以自己设别名（只存本地）。

## 六、数据在哪、怎么备份

全部在解压目录的 `data\` 下：

| 文件 | 内容 |
|---|---|
| `assistant.db` | 账号、历史快照、签到记录、抽卡快照 |
| `vault.json` | 加密后的登录凭证 |
| `run.log` | 运行日志（出问题看这个） |
| `python_path.txt` | 上次找到的 Python 路径缓存 |

**备份就复制整个 `data` 文件夹。换电脑时把它一起带过去**（同一台机器、同一个 Windows 账户下才能解密凭证；否则需要重新授权账号）。

**注意：`data` 里有你的登录凭证，别发给别人。**

## 七、常见问题

**打开页面是空白 / 502**
系统代理把回环地址也代理了。启动脚本已经设了 `NO_PROXY=127.0.0.1,localhost`，如果你自己另开了代理软件，把 `127.0.0.1` 加进例外，或先关掉代理。

**提示端口被占用**
说明已经有一个实例在跑了，直接用浏览器打开 `http://127.0.0.1:8765/` 就行。要重启就先关掉那个窗口 / 在任务管理器结束对应的 python 进程。

**账号显示「待重登」**
凭证过期了，点「重新授权」再走一次验证码。

**注意一个容易踩的坑：同一个账号，官方塔吉多 App 和这个工具不能同时在线。**你在官方 App 登录一次，工具这边的凭证立刻被顶掉（接口返回 402）。2026-11-09 实测两次都是这个规律：11:31 用 App 看数据 → 11:32 工具 402；12:15 用 App 核对 → 12:15 工具 402。所以核对完回到工具需要重新授权一次。

**输入验证码时手滑点到外面，弹窗关了怎么办**
直接再点「重新授权」。同一个号码还在 10 分钟内，工具会**直接接回刚才那一步**，不用重发短信、也不用等，验证码输进去就行（弹窗里会显示会话剩余时间）。如果确实没收到短信，点「重新发送验证码」——60 秒冷却过后就能重发。

以前这里有个坑：会话只存在页面上，关掉弹窗就丢了，服务端却还占着会话，于是只能干等 10 分钟。现在会话在服务端留着、页面也存了一份，关掉、刷新、换标签页都不会丢。

**签到显示成功但邮箱一直空**
1. 点「签到详情」→「补投递」（免费、可重复）；
2. **完全退出游戏**（不是切后台）再重进；
3. 还是没有就等几分钟再重进一次，官方说明有延迟。
4. 仍然没有 → 看 `data\run.log` 里有没有 `signin.deliver` 失败记录。

**都市活力显示 0，但游戏里明明是满的**
规则很简单：**周一 05:00 活力归满，工具默认就按满显示**，不等服务端承认。所以周一早上打开看板，即便显示的是上周日抓到的旧数据，也会直接按满展示（标「周重置 · 按满显示」）。
原因：服务端要等你在游戏里**花掉第一点**才重算，在这之前接口会返回旧值——上周没花完的号回显旧数（比如 256），上周花光的号返回 0。这两种旧数都不会被当成你的真实余量。
**只要你花了，接口就会给出真实值，工具立刻用它覆盖**。本周一旦读到过真实值（哪怕真的花到 0），一律以接口为准，不会再被改成满。想确认精确余量，进游戏花一点再刷新即可。

**周本次数显示「—」，官方 App 明明是 2/3**
这个数字是**存档字段**：本周进过游戏、存档写入并退出之后，服务端才会把它带进角色数据。你刚打完周本、人还在游戏里时，接口里根本没有这个字段（不是 0 次，是整条缺失），所以工具显示 `—` 并标「待同步 · 退出游戏后刷新」。
**做法：完全退出游戏 → 点一下刷新**，有真值时就会显示 `x/3` 并标「接口真值」。
已实测确认（2026-11-09，同一角色）：退出游戏并重新授权前 **22 个字段、没有该键**；退出后 **23 个字段、`weekcopiesremainCnt=2`**，与官方 App 的 `2/3` 完全一致。同期没进过游戏的另一个号仍缺这个键。
工具绝不拿官方前端的常量 `3` 顶上；还没同步到的号只显示「未同步」。如果退出游戏后刷新还是 `—`，把时间告诉我，我按实际返回继续查。

**备注保存报错 `readonly database`**
偶发的数据库锁竞争，稍等几秒重试即可，数据不会坏。
