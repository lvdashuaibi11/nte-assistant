# 异环第三方助手（NTE Assistant）

一个跑在自己电脑上的《异环》多账号管理小工具。开一个本地网页，把几个号的签到、体力、活跃度、周本次数和抽卡记录摊在一屏里看完。

**不联云、不装依赖、不打包你的数据** —— 只用 Python 标准库（`http.server` + `sqlite3` + `ctypes`），凭证用 Windows DPAPI 加密后留在本机。

> 非官方项目，与完美世界 / 塔吉多无关。仅供个人自用，详见文末[免责声明](#免责声明)。

---

## 它解决什么问题

官方塔吉多 App 只能一个号一个号地看，切号要重新登录，而且**用 App 登录会把第三方工具的凭证顶掉**（见[已知限制](#已知限制)）。这个工具把多账号摊平成一张看板：

| 模块 | 内容 |
|---|---|
| 每日签到 | 游戏内签到（`gameId=1289`）+ 签到奖励**自动补投递**到游戏邮箱 |
| 四项数据 | 本性像素（体力，含恢复估算）、都市活力、活跃度、周本次数 |
| 抽卡统计 | 抽卡记录汇总、按卡池筛选、出货率与保底进度 |
| 多账号 | 一屏并排、单个号独立刷新、支持备注名与分组 |
| 补签 | 手动触发，消耗呗果前二次确认（**自动化永远不碰补签**） |

几个坑是踩出来的，代码里都留了注释和测试：

- **签到发奖要两步**。`POST /apihub/awapi/sign` 只写社区侧记录，奖励进不了游戏邮箱；必须再调一次 `POST /usercenter/api/autoBindGameRole`（`gameId` + `roleId`）建角色联动。两个请求**同一秒发出会空跑**，所以签到成功后再排一次延迟 30 秒的投递，遇错原地重试 3 次。
- **都市活力是周刷新的懒字段**。周一 05:00 归满，但服务端不会主动回填：本周没花过就返回 `0`，上周没花完则**回显上周残留值**。展示层在快照早于重置点时直接按上限显示（不落库），刷新层只拦 `0` 和回显这两种假数，本周读到过真值就一律照抄。
- **周本次数是存档字段**。本周没进过游戏、或还停在游戏里没退出，接口返回的 22 个键里根本没有 `weekcopiesremainCnt`；正常退出后才变 23 个键。所以看板会区分「接口真值 / 待同步 / 未同步」三种角标，而不是硬编 `0/3`。

## 快速开始

### 方式一：直接跑源码（需要 Python 3.10+）

```bash
git clone https://github.com/lvdashuaibi11/nte-assistant.git
cd nte-assistant
python app.py
```

浏览器打开 <http://127.0.0.1:8765/>，右上角「导入账号」→ 手机号 + 短信验证码。

Windows 用户也可以双击 `启动.bat`（前台）或 `后台启动.bat`（常驻）。脚本会自动找 Python，找不到会提示装哪个。

### 方式二：免安装版

从 [Releases](https://github.com/lvdashuaibi11/nte-assistant/releases) 下载 `异环助手_v*_免安装版.zip`，解压后双击 `启动.bat`。包内自带 Python 3.12 embed 运行时（`runtime/`），什么都不用装。

> 路径别带中文和空格更稳，例如 `D:\nte-assistant`。
> 必须用 `127.0.0.1`，不要用 `localhost` 或局域网 IP —— 服务只绑回环地址。

界面细节、每个按钮干什么、常见报错怎么处理，都写在随包的 [`使用说明.txt`](使用说明.txt) 里。

## 默认是「只看不改」

首次运行有两道闸，都得你手动打开：

| 开关 | 默认 | 说明 |
|---|---|---|
| 允许写操作 | **关** | 关着的时候签到/补签按钮是灰的，只做只读刷新 |
| 定时自动化 | **关** | 即使开了，**也永远不会自动补签**（补签花呗果，只能手动点） |

## 目录结构

```
nte-assistant/
├─ app.py                  # 入口：http.server + 路由，只监听 127.0.0.1
├─ core/
│  ├─ adapter.py           # 请求签名、端点调用、字段映射
│  ├─ auth.py              # 短信授权会话（同号复用、60s 重发冷却、10min TTL）
│  ├─ service.py           # 业务编排：刷新队列、签到、延迟投递、周重置
│  ├─ db.py                # SQLite 存储与快照（含旧库自动迁移）
│  ├─ vault.py             # 凭证加密（Windows DPAPI）
│  ├─ gacha.py             # 抽卡统计与卡池归类
│  ├─ crypto.py            # AES-ECB 登录参数加密
│  ├─ config.py            # 路径与环境变量（NTE_PORT / NTE_DATA_DIR）
│  └─ logutil.py           # 结构化日志 + 手机号/token 脱敏
├─ adapters/1.2.8.json     # 端点、签名常量、字段映射（热加载，改版只改这里）
├─ web/                    # 单页界面（原生 JS，无框架无构建）
├─ tests/test_core.py      # 103 项单测，全部离线、mock 掉网络
├─ runtime/                # 免安装版的 Python 运行时（.gitignore，不提交）
└─ data/                   # 你的账号与快照（.gitignore，绝不提交）
```

改官方接口不需要动 Python：`adapters/1.2.8.json` 里端点、签名常量、字段名都是数据，官方改版时改这一个文件即可。

## 数据与隐私

- 所有数据在 `data/assistant.db`（SQLite）与 `data/vault.json`（凭证）。**没有任何上报、没有遥测、没有第三方请求。**
- 凭证用 Windows DPAPI 加密，绑定当前 Windows 账户与本机，拷到别的电脑解不开，只在本机有效。
- 日志 `data/run.log` 写入前会脱敏手机号与 token。
- 浏览器端只在本地存两样东西：界面显示偏好（自定义别名/排序），以及一个「有未完成授权会话」的标记（不含手机号，会话 10 分钟过期）。
- 换数据目录：设环境变量 `NTE_DATA_DIR` 指向别处，可以做多套互不干扰的数据。

## 已知限制

- **凭证是单会话的**。`accessToken` 被新登录顶掉就失效，而且**用官方 App 登录同一个号会把工具的凭证顶掉**，只能重新短信授权。没有可用的 `refreshToken` 轮换，所以别指望挂着就能一直不掉线。
- **周本次数是存档字段**，见上文。没退出游戏时读不到，不是接口坏了。
- **都市活力在周一 05:00 后可能是估算值**。服务端懒回填，展示层会按上限显示并在后端标记为估算，等你本周花过一次就会变成真值。
- **只支持 Windows**。凭证加密依赖 DPAPI，界面也是按 Windows 路径和批处理写的。

## 关于签名常量

`adapters/1.2.8.json` 里的 `secret` / `cloudSecret` / `dsSecret` 以及 `bid`、`deviceModel` 等，是从官方客户端提取的请求签名常量，用于构造与官方 App 一致的请求头。这些值**在社区的公开逆向项目中早已公开**（见[致谢](#致谢)），本仓库沿用同一组，仅为可复现，不代表任何授权。

它们不是你的账号凭证，泄露它们不等于泄露你的账号。但官方随时可能更换，届时需要自行更新这一份 JSON。**如果你在意这层风险，fork 后不要把这份 JSON 再公开分发。**
